<h3>Linear programming desktop app</h3>

<p>This app automates several methods of linear programming, making a linear programming calculator. <br>
<ul>
  <li>Primal Simplex</li>
  <li>Primal Simplex Revised</li>
  <li>Dual Simplex</li>
  <li>Branch and Bound</li>
  <li>Branch and Bound Knapsack</li>
  <li>Cutting Plane</li>
  <li>Sensitivity Analysis</li>
</ul>
</p>
